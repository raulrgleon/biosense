Glucosa

Canal electroquímico CH1. Corriente de sensor, TIA, filtro y ADC. La sensibilidad por defecto es provisional.

Oxígeno

Segundo canal electroquímico, CH2, con su propio TIA y filtro. Las unidades son de simulación, no mmHg.

Temperatura

Tercer canal. Hoy entra por control. El ADC CH3 queda reservado para un sensor físico posterior.

  • REST /api/v1 y Swagger. Misma validación que la UI.
  • MCP app.biosense.dev/mcp — Streamable HTTP, API key u OAuth 2.1.

Lo que no es

No es un glucómetro. No sustituye laboratorio. Los coeficientes marcados PROVISIONAL no son curvas de electrodo reales. El audience OAuth del MCP es https://app.biosense.dev/mcp.
